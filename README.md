# 英伟达 GPU 选型对比工具

英伟达数据中心 / 工作站 / 消费级 GPU 规格对照与选型对比，共收录 **65 款型号**（Blackwell Ultra / Blackwell / Hopper / Ada / Ampere / Turing 等架构）。

## 在线使用

打开 `index.html`（部署后访问 `https://<你的用户名>.github.io/<仓库名>/`）：

- 左侧型号库勾选 1–8 款 GPU，右侧自动生成 15 组指标对比图表
- 覆盖 FP64 / FP32 / TF32 / FP16 / INT8 / INT4 / FP4、CUDA 核心数、显存容量 / 带宽、TDP 功耗
- 算力均标注稠密 / 稀疏口径（² = 稀疏口径，≈ = 推算值）

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 在线选型对比工具（单文件，无依赖，双击即可离线使用） |
| `英伟达系列GPU对照_更新校正版.xlsx` | 完整对照表：速览对比（62 款）/ 选型对比（下拉自动对比）/ 数值数据（65 列）/ 校对与更新说明 |

## 数据口径

- 算力为理论峰值，² 标记为稀疏口径，≈ 为推算值
- 数据来源：NVIDIA 官方产品页 / 官方规格表，逐条校对记录见 Excel「校对与更新说明」表
- 持续更新，欢迎 Issue / PR 纠错
